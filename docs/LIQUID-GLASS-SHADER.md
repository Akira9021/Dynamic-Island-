# Liquid Glass: настоящий шейдер

Реализация материала Apple Liquid Glass на AGSL (Android Graphics Shading Language).
В отличие от прежней имитации на Compose, здесь настоящий фон под островом
**преломляется по Снеллиусу**, а не просто затемняется и размывается.

## Что делает шейдер

Один фрагментный проход (`LIQUID_GLASS_AGSL` в `island/LiquidGlassShader.kt`):

1. **Суперэллипс-SDF** задаёт линзу. Для капсулы это стадион, для карточки —
   скруглённый прямоугольник с непрерывным (squircle) углом.
2. **Преломление.** По расстоянию до края считается толщина стекла, затем
   угол падения и угол преломления (`IOR = 1.45`). Нормаль SDF задаёт
   направление смещения. Край линзы смещает фон сильнее, центр — почти нет.
3. **Дисперсия.** R, G и B сэмплируются с разным смещением (±6 %), поэтому на
   контрастных границах появляется радужная кромка, как у настоящего стекла.
4. **Fresnel.** У касательных углов стекло отражает больше: по SDF считается
   узкая световая кромка.
5. **Glare.** Направленный блик на кромке; направление зависит от наклона
   телефона (`IslandBus.glassTilt`) и от угла света.
6. **Frosted body.** Край линзы резкий, тело — матовое (сильный box-blur
   уменьшенной копии фона). Кромка широкая: толщина — 42 % высоты (до 22 dp),
   световой ореол — 34 % (до 18 dp), смещение — 0.75 толщины.
7. **Тонирование.** `glassOpacity` даёт лёгкую тонировку, а не плотную заливку:
   при 60 % фон хорошо виден, при 100 % стекло плотнее, но остаётся
   полупрозрачным. По умолчанию 60 %.

Плюс лёгкая вертикальная вуаль и блик-«пробежка» при смене содержимого.

## Откуда берётся фон

`service/GlassBackdropCapture.kt`:

- На **Android 14+** используется `AccessibilityService.takeScreenshotOfWindow()`
  для окна **под** островом. Это важно: обычный `takeScreenshot()` снял бы сам
  остров и получилась бы обратная связь.
- Снимок берётся по всей полосе острова (а не по текущей капсуле), чтобы при
  раскрытии не упираться в край текстуры. Он уменьшается до 900 px по длинной
  стороне, размывается тремя box-проходами и публикуется в `GlassBackdropState`.
- Частота — около 2,6 кадра в секунду (ограничение accessibility screenshot).
  Для строки состояния этого достаточно; при прокрутке контента стекло может
  отставать на кадр.
- В экономии заряда, при выключенном экране и при скрытом острове захват
  останавливается. Последний кадр остаётся статичным.

На **Android 13** шейдер есть, но окно под островом снять нельзя, поэтому
используется прежний материал Compose. На **Android 12 и ниже** — тоже Compose.

## Где включается

`Оформление → Цвет и рамка → Материал и эффекты`:

- «Стекло» — сам материал.
- «Плотность стекла» — сила лёгкой тонировки. По умолчанию 60 %: фон
  просвечивает и остаётся цветным, как на референсах Apple, а текст читается.
- «Живое преломление» (`glassShader`) — настоящий шейдер. Выключение
  возвращает Compose-материал.

Для работы нужны спец. возможности (они и так нужны острову). После обновления
приложения службу может понадобиться выключить и включить заново, чтобы Android
перечитал `canTakeScreenshot`.

## Ограничения

- Защищённые окна (`FLAG_SECURE`) и некоторые системные экраны снять нельзя —
  там автоматически остаётся Compose-материал.
- На рабочем столе снимок окна лаунчера может не содержать обоев; в этом случае
  стекло будет темнее, чем хотелось бы.
- Живые примеры в настройках используют шейдер на синтетическом фоне
  (мягкий цветной градиент с пятнами). Реальный экран им не нужен, поэтому
  превью работает и без спец. возможностей.
- Захват экрана — это доступ к содержимому других приложений. Приложение не
  сохраняет снимки на диск и не передаёт их по сети: кадр живёт в памяти до
  следующего кадра.

## Проверки

- `app/src/test` — прежние тесты материала и геометрии.
- `app/src/androidTest/.../LiquidGlassShaderTest.kt` — компилирует AGSL на
  устройстве, рисует капсулу поверх полосатого фона и проверяет смещение
  (refraction) и разделение каналов (dispersion).
- `LiquidGlassRenderingTest.kt` — регрессия Compose-материала (fallback).

Ручная проверка: включить стекло и «Живое преломление», открыть приложение с
контрастным верхним краем (браузер, галерея, Настройки), раскрыть и свернуть
остров. На кромке должны быть видны смещение фона и цветная дисперсия; при
наклоне телефона блик смещается. Проверено на эмуляторе API 36: шейдер
рисуется, кадр захватывается, над белыми Настройками карточка становится
серой, а строка поиска за стеклом заметно изгибается. На рабочем столе
лаунчер может не отдавать обои в снимок окна — тестируйте внутри приложения.
