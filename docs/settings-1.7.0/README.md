# Настройки тестовой 1.7.0

## Где находятся настройки

- **Функции → События → Подключения**: Wi-Fi, наушники, USB, VPN и точка доступа.
- **Функции → События → Для разработчиков**: отладка USB и Wi-Fi.
- **Функции → События → Показ событий**: время на экране и задержка. Они больше не смешаны со скоростью анимации.
- **Функции → Поведение**: видимость, режим пустого острова, приоритет музыки, сторона второй активности, AOD, шторка, расписание.
- **Функции → Жесты**: один выбор для горизонтального свайпа — выключен, треки или карточки.
- **Оформление → Цвет и рамка**: отдельно выбрать капсулу или карточку; заливка, рамка, материал и кнопки.
- **Оформление → Размер и форма**: размеры с активностью, ширина/высота карточки, масштаб содержимого, радиус углов.
- **Оформление → Раскрытие острова**: только визуальные анимации. Сброс анимаций не меняет время событий.
- **Уведомления**: вид плашки, значки и цвет ответа с собственным примером.

## Рамка без пересекающихся переключателей

Для карточки есть три взаимоисключающих режима:

1. **Как у капсулы** — повторяются цвет, прозрачность и все четыре стороны рамки. Выключенная рамка капсулы означает отсутствие рамки у карточки.
2. **Без рамки** — выключена независимо от капсулы; старые настройки отдельных сторон не возвращают её неожиданно.
3. **Своя рамка** — отдельные параметры карточки. Выбранный цвет больше не перекрывается цветом музыки/активности.

В своей рамке выбирается **Одинаковая толщина** или **По сторонам**. Неиспользуемый общий ползунок скрыт. Ноль скрывает конкретную сторону. Выбор одинаковой толщины удаляет старые скрытые переопределения.

Материал и прозрачность общие для капсулы и карточек, это подписано в редакторе. Стекло использует выбранную заливку карточки; плотность 100% действительно непрозрачна. Затемнение снизу заметно на светлом цвете, на чёрном оно визуально ничего не меняет.

## Живые примеры

Пример закреплён над прокручиваемыми настройками. Доступны часы, музыка, сообщение и таймер. В поведении можно увидеть музыку вместе с таймером: приоритет и сторона пузыря меняются сразу. Редактор кнопок показывает таймер, шрифт — сообщение.

Рисуются настоящие `IslandBody`, `CompactContent` и `ExpandedContent`, с той же поверхностью, рамкой, шрифтами и анимациями. Пример уменьшен до области просмотра, поэтому не служит калибровкой положения камеры — для этого остаётся «Положение и размер».

Пример не отправляет уведомления и не управляет телефоном. Действия заблокированы как для касаний, так и для служб доступности. Он не удерживает и не закрывает реальные уведомления.

В событиях пример автоматически появляется при изменении настройки; длительность и задержка демонстрируются прямо на нём. Кнопка **Повторить** показывает его снова.

## Реальные системные события

Переключатель в приложении разрешает показ события, а не включает VPN, точку доступа или отладку на телефоне. Под каждым дополнительным событием показано состояние, реально полученное от Android, отдельно от демонстрации плашки.

- VPN наблюдается без лишних ограничений `NOT_VPN`/`TRUSTED`/`NOT_RESTRICTED`. Добавлено перечитывание состояния при изменении возможностей сети и резервное обновление.
- Отладка читается через наблюдатели настроек и резервное обновление при включённом экране. Отсутствующее значение не превращается в ложное «Выкл».
- Первое чтение и повторная отправка одного состояния не являются событиями. Настоящее изменение VPN/отладки не теряется во время начальной паузы запуска службы.
- **Wi-Fi-отладка требует подключённого Wi-Fi**: Android может сразу вернуть переключатель в выключенное состояние, если сети нет. Это не потерянная плашка.
- Состояние точки доступа доступно не на всех прошивках. Если телефон его не передал, это явно показано; кнопка «Пример» не выдаётся за доказательство поддержки устройства.

## Проверки

Проверки логики охватывают наследование/выключение рамок, совместимость сохранённых настроек, взаимоисключающие режимы жестов, пустой капсулы и скрытия источника, определения изменений системного состояния, а также прежние регрессии.

Android-тесты проверяют редактор рамки на экране шириной 360 dp, закрепление примера при прокрутке, отсутствие воздействия на реальные уведомления и категории событий. Отдельный тест переключает системную Wi-Fi-отладку с разрешением тестового окружения и проверяет доставку события в очередь острова. Для него нужен подключённый Wi-Fi. Тесты запускаются на отдельном эмуляторе и используют тестовые настройки.

### Результат проверки

- Версия: **1.7.0**, код версии **14**; ветка `test-1.7.0`.
- `assembleDebug assembleDebugAndroidTest testDebugUnitTest lintDebug assembleRelease`: успешно, JDK 17 / SDK 35.
- JVM: **55 тестов**, без ошибок и пропусков.
- Android 35, экран 720 × 1600 / 320 dpi (**360 dp**): **3 UI-теста прошли**. Проверены взаимоисключающие настройки рамки, закрепление примера, сохранение реального `noticeHold` и отсутствие доступных телефонных действий в примере, навигация и категории событий.
- **1 системный Android-тест прошёл отдельным запуском**: начальное чтение VPN, изменение системной Wi-Fi-отладки, наблюдение изменения и доставка настоящего события в остров. Тест учитывает системный запрос подтверждения отладки для новой Wi-Fi-сети и возвращает исходное значение.
- Lint: **0 ошибок, 22 предупреждения** — версии библиотек, существующие рекомендации Compose, XML, векторные ресурсы и физические стороны камеры.
- Французский и испанский: по **786** строк. Остальные языки используют существующий английский fallback для недостающих новых подписей.
- Локально собраны Debug APK и оптимизированный неподписанный Release APK. Релиз, тег и основная ветка не публиковались.

Полная проверка настоящего подключения/отключения VPN и точки доступа на телефонах разных производителей остаётся аппаратной проверкой. Наличие примера плашки не означает, что прошивка передаёт такое событие.

### Повторение Android-проверок

На отдельном тестовом устройстве с подключённым Wi-Fi:

```sh
./gradlew assembleDebug assembleDebugAndroidTest
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb install -r app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk
# Для медленного программного эмулятора: заранее скомпилировать обе тестовые программы.
adb shell cmd package compile -m speed -f com.akira.island
adb shell cmd package compile -m speed -f com.akira.island.test
adb shell am instrument -w -r -e class com.akira.island.ui.SettingsExperienceTest com.akira.island.test/androidx.test.runner.AndroidJUnitRunner
adb shell am instrument -w -r -e class com.akira.island.service.SystemEventsDeviceTest com.akira.island.test/androidx.test.runner.AndroidJUnitRunner
```

Эти тесты меняют настройки приложения; системный тест также временно меняет Wi-Fi-отладку. Они предназначены для тестового устройства. Проверки на телефонах перед публичным выпуском перечислены в [общем руководстве](../TESTING-1.7.0.md).
