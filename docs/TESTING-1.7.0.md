основной ветки или `v*`-тега; отправка тестовой ветки собирает APK-артефакт.

## Ограничения платформы

Без системных привилегий нельзя надёжно прятать чужие значки строки состояния,
показывать достоверные индикаторы камеры/микрофона/геолокации других приложений,
отключать Samsung Now Bar или произвольно запускать закрытые сценарии прошивки.
Такие возможности не имитируются. Системные индикаторы приватности остаются Android.
Для режимов телефона можно закрепить соответствующее приложение в ярлыках панели.

Если приложение не передаёт время/счётчик/стабильную идентичность сообщения,
одинаковое новое сообщение невозможно безошибочно отличить от обновления старого.
Очередь ограничена 64 событиями; переполнение удаляет самое старое.

Шагомер показывает накопленные аппаратные изменения с момента первого включения
в этот день, не выдаёт накопленный счётчик с загрузки телефона за дневной результат.
Погода опциональна и передаёт выбранный город/координаты Open-Meteo (CC BY 4.0).

## Автоматические проверки

JDK 17, Android SDK 35, Gradle из wrapper:

```sh
./gradlew --no-daemon --max-workers=4 testDebugUnitTest lintDebug assembleDebug assembleRelease
```

Тесты проверяют метки LRC и offset, идентичность сообщений, безопасное удаление,
сопоставление платежей, показания батареи, объединение загрузок, чтение старых
настроек, переводы, разбор погоды и дневные шаги. Сборка release создаёт локальный
неподписанный APK и сама по себе ничего не публикует.

## Проверки на телефонах перед публичным релизом

1. Установить поверх прежней тестовой сборки с тем же ключом, проверить сохранение настроек.
2. Дать доступ Accessibility и уведомлениям; перезапустить процесс/экран и проверить восстановление.
3. WhatsApp/Snapchat: разные и одинаковые последовательные сообщения, ответ, чтение, удаление,
   тихие каналы, блокировка, несколько приложений одновременно, постоянные уведомления.
4. Spotify/YouTube Music: вступление до первой LRC-строки, pause/seek/buffering,
   несинхронизированный текст, смена песни/обложки/версии записи.
5. Звонки сотовые и Discord: ответ/отклонение/скрытие и отказ PendingIntent.
6. Поворот в обе стороны, игры, шторка, AOD, вырез, большие шрифты и длинная история.
7. Зарядка после сна, неподдерживаемые аппаратные показатели, наушники.
8. Реальный платёж T-Банк/Belkart: экран, результат, уведомление, отказ/возврат,
   два платежа с одной суммой и разные валюты. Старый перевод не должен стать новой оплатой.
9. Отсутствие сети/датчика шагов/специального доступа к яркости должно корректно
   отключать только соответствующую необязательную функцию.

## Результат текущего прогона

- `testDebugUnitTest lintDebug assembleDebug assembleRelease`: успешно.
- 42 теста, 0 ошибок/падений, 0 пропущенных.
- Lint: 0 ошибок, 19 предупреждений (в основном версии зависимостей и рекомендации Compose).
- Debug APK и оптимизированный неподписанный release APK собраны локально.
- Программный Android 35 без KVM не завершил загрузку примерно за 7 минут;
  установка APK завершилась по лимиту времени. Runtime-проверка приложения
  на эмуляторе не подтверждена; проверки на телефонах из списка выше остаются необходимыми.
- Французская/испанская таблицы: по 706 строк; для новых строк других языков
  действует существующий английский fallback.
