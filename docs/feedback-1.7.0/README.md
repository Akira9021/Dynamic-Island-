## Подтверждённые ошибки из скриншотов и видео

1. **Три лишние кнопки в сообщении:** присутствовали в `Compact.MessageCard` при подробном просмотре. Удалены «Открыть», «Удалить», «Свернуть»; сохранены ответ, отметка прочитанного и история. Для полных подписей действий используется вся ширина карточки; при крупном шрифте кнопки переходят на следующую строку. Открытие приложения по настроенному длительному нажатию и удаление через выбранный жест остаются доступны.
2. **Запись экрана превращалась в навигацию:** `NotificationParser` разрешал `LiveParser` перезаписать уже распознанный секундомер. Добавлен приоритет явной записи, в том числе сообщения SystemUI «Tap here to stop recording» без массива кнопок. Явный contentIntent остановки используется как стоп; обычный intent не считается остановкой без подтверждающего текста. Обновления без своего времени сохраняют начало записи. Дубликат полоски загрузки убирается.
3. **Таймкод распадался на строки:** фиксированные 34/38 dp заменены минимальной естественной шириной и одной строкой без переноса.
4. **Таймер в пустом острове вытеснял счётчик:** на узкой карточке старт вынесен под регулировку; широкая сохраняет одну строку.
5. **Музыка на паузе могла исчезнуть во время чтения:** таймер скрытия теперь ждёт закрытия раскрытого плеера.
6. **Размытие могло оставаться после анимации или отключения эффекта:** renderEffect теперь явно очищается; дорогие объекты переиспользуются ограниченным кешем.
7. **Минимизированные сообщения терялись даже с «Тихими»:** фильтр теперь учитывает IMPORTANCE_MIN; IMPORTANCE_NONE и DND остаются запрещены.
8. **Индонезийский в новых функциях оставался английским:** добавлены 200 отсутствовавших подписей; выбор системного языка учитывает конфигурацию приложения, включая язык приложения Android.

## Что уже было и не реализовывалось повторно

- Повторные сообщения: существующий MessageDeduplicator отличает новое время/счётчик от повторного обновления одного уведомления; тесты сохранены. Если источник присылает совершенно одинаковые поля без идентификатора/времени, безошибочно различить события нельзя.
- Фиксация у камеры в landscape, размеры под отверстие, радиусы, ярлыки, погода, поддержка сессий музыки и синхронных LRC уже есть. Само наличие старого комментария на видео 1.6.5 не доказывает баг в 1.7.0.
- Инструкции ограниченных настроек Android 13+, банковских приложений и настройки системных heads-up уже есть; защита Android не обходится.

## Новые настройки и дизайн

- Новые варианты кастомизации собраны в аккуратные группы радиокнопок Material 3 в существующей тёмной палитре. Остальной интерфейс не переделывался.
- Поиск доступен из «Функций» и «Оформления». Ищет категории и функции, открывает нужный раздел, сохраняет запрос при возврате. Поле поиска закреплено. Запрос никуда не отправляется.
- «Скрывать при записи экрана» находится в «Поведении». Опция скрывает весь остров на телефоне, пока распознана запись; это не обещание исключить только overlay из произвольного видеозахвата. На прошивках без доступного уведомления определить запись нельзя.
- `SettingsPreview.kt` и `AppearancePreview.kt` не изменялись. Живые примеры остаются на месте и продолжают использовать общий рендер.

## Производительность и батарея

| Участок | Изменение |
| --- | --- |
| Плеер | Заголовок/обложка/кнопки вынесены из тикающего участка. Полоса читает время при рисовании; подписи времени обновляются раз в секунду, синхронная лирика — с прежней частотой. |
| Таймер на паузе | Периодический UI-таймер останавливается. Секундомер с долями секунды сохраняет точность обновления. |
| VPN / отладка | Резервного периодического опроса нет при выключенном экране и отключённых событиях. При настроенной экономии — реже; системные callbacks остаются основным источником. |
| Поддерживающая служба | Нет минутного переподключения при выключенном экране. |
| Удержание уведомления | Вместо опроса каждые 200 мс ожидание изменений Flow. |
| Анимации | Кеш до 48 эффектов на переход, шаг радиуса 0,5 px; нулевой эффект удаляется явно. |
| Wake-lock | Ограничение 3 с сохранено; добавлено раннее освобождение в finally при завершении или отмене корутины. |
| Язык | Корневая область подписывается только на язык, а не на все изменения ползунков/таймера. |

Эмулятор Android 35 работает без KVM. Он подходит для функциональных и геометрических проверок, но его FPS и энергопотребление не являются измерением реального телефона. Процент экономии батареи и отсутствие jank на всех устройствах не заявляются.

## Что остаётся нереализованным или ограниченным

- Раздельный заряд левого/правого наушника и кейса: общего заряда из Android недостаточно; нужны доступные данные конкретной модели. Не отображаются вымышленные проценты.
- Ошибка пароля/отпечатка и Face ID в чужих приложениях: достоверные результаты их аутентификации обычному приложению не предоставляются. Существующие события блокировки/разблокировки не подменяются фиктивной проверкой лица.
- Полный центр управления iPhone, все страницы Brief/часов из #23 и жест прокрутки чужого приложения наверх в этот патч не добавлены. Прокрутка возможна лишь для доступных Accessibility-узлов и не универсальна.
- Скрытие значка приложения в лаунчере пока не добавлено: нужен понятный путь восстановления доступа к настройкам; скрывать приложение без него нельзя.
- Выключение только домашнего индикатора Samsung Now Bar, скрытие чужих значков строки состояния и надёжные индикаторы использования чужими приложениями камеры/микрофона не реализуются обычными публичными API.
- Проверка Spotify/YouTube Music, Snapchat, Bluetooth-кейса, ColorOS/Techno, банков и фактического расхода заряда требует соответствующих приложений и телефонов. Это не считается подтверждённо исправленным только по успешной сборке.
