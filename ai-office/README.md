# 🏢 AI Office

Команда ИИ-агентов в Telegram на Claude. Каждый агент — отдельный бот со своей ролью:
вы ставите задачу в общем чате, руководитель раскладывает её на подзадачи,
агенты берут их в работу, отчитываются, а в конце руководитель подводит итог.

```
Вы:     /task запускаем канал про ИИ, нужен план на первую неделю
Alice:  Делаем так: Leo — контент-план, Sam — аудитория и метрики, Kevin — автопостинг.
Kevin:  Взял задачу #4: автопостинг
Leo:    Взял задачу #5: контент-план на неделю
...
Leo:    ✅ #5 контент-план на неделю — (готовый план)
Alice:  📋 Итог — что сделано и что дальше
```

Состав команды по умолчанию (меняется в `agents.toml`):

| Агент | Роль |
|---|---|
| 👩‍💼 Alice | ассистент и руководитель — раздаёт задачи |
| 🧑‍💻 Kevin | CTO — код, техника, автоматизация |
| 📱 Leo | SMM — посты, сценарии, контент-планы |
| 📊 Sam | аналитик и маркетолог — цифры, аудитория, воронки |

## Что понадобится

1. **Ключ Claude API** — [platform.claude.com](https://platform.claude.com) → API keys.
   Это отдельная оплата по токенам, подписка claude.ai сюда не входит.
2. **Боты** — в [@BotFather](https://t.me/BotFather) создайте по боту на агента (`/newbot`).
   Можно начать с одного Alice, остальных добавить потом.
3. **Ваш id в Telegram** — напишите [@userinfobot](https://t.me/userinfobot).
4. **Сервер, который не выключается** — любой VPS с Docker (бот работает, пока запущен процесс).

## Запуск

```bash
git clone https://github.com/Akira9021/Dynamic-Island-.git
cd Dynamic-Island-/ai-office
cp .env.example .env
nano .env            # OWNER_ID, ANTHROPIC_API_KEY, TOKEN_ALICE, ...
docker compose up -d --build
docker compose logs -f   # в логе появятся @имена ботов
```

Без Docker: Python 3.11+, затем `pip install -r requirements.txt` и `python -m office`.

## Общий чат команды

1. Создайте группу в Telegram и добавьте туда всех ботов.
2. У руководителя (Alice) отключите приватность: @BotFather → `/setprivacy` → выбрать бота → **Disable**.
   Иначе он не увидит обычные сообщения в группе. Для остальных ботов это не нужно.
   Если бот уже был в группе, после смены настройки удалите его и добавьте снова.
3. Напишите в группе `/id` и впишите число в `OFFICE_CHAT_ID` — тогда `/task` из лички тоже пойдёт в группу.
4. Для ленты задач («📌 #12 → Kevin…», «✅ Kevin закрыл #12») создайте ещё одну группу или канал
   с Alice, узнайте `/id` и впишите в `TASKS_CHAT_ID`. Если не указывать, ленты просто не будет.
5. Перезапустите: `docker compose restart`.

## Как общаться

- `/task текст` — задача всей команде.
- В группе отвечает тот, кого позвали: `@бот`, ответом на его сообщение или по имени в начале
  («Leo, придумай заголовок»). Если никого не позвали, отвечает руководитель.
- В личке с любым ботом — обычный диалог с этим агентом, он помнит последние 30 сообщений. `/reset` — забыть.
- `/tasks` — последние задачи, `/team` — состав, `/help` — справка.

Офис слушается только владельца (`OWNER_ID`): сообщения остальных боты игнорируют.

## Своя команда

Откройте `agents.toml`: у агента есть `key`, `name`, `role`, `emoji`, `prompt` (характер и обязанности)
и `token_env` — имя переменной с токеном в `.env`. Добавили агента — добавьте его токен в `.env`
и перезапустите. Руководитель помечается `lead = true`.

## Настройки `.env`

| Переменная | Что это |
|---|---|
| `OWNER_ID` | ваш id в Telegram (обязательно) |
| `ANTHROPIC_API_KEY` | ключ Claude API (обязательно) |
| `TOKEN_*` | токены ботов из `agents.toml` |
| `OFFICE_CHAT_ID` | id общего чата команды |
| `TASKS_CHAT_ID` | id чата-ленты задач |
| `CLAUDE_MODEL` | модель, по умолчанию `claude-opus-5-5`; дешевле — `claude-sonnet-5-5`, ещё дешевле — `claude-haiku-5-5` |
| `CLAUDE_EFFORT` | глубина размышлений: `low`, `medium` (по умолчанию), `high` |
| `HISTORY_LIMIT` | сколько сообщений лички помнить (30) |
| `MAX_PARALLEL_TASKS` | сколько задач выполнять одновременно (3) |

## Ограничения

- Агенты — это Claude без доступа к интернету, вашим файлам и сервисам: они пишут тексты, код,
  планы и расчёты, но сами ничего не публикуют и не запускают.
- Telegram не показывает ботам сообщения других ботов, поэтому разговор агентов между собой
  ведёт сам процесс офиса — снаружи это выглядит как обычная переписка в группе.
- Каждый ответ агента — платный запрос к Claude API. Задача на 3 агентов — это примерно 5 запросов
  (план, три исполнителя, итог).

## Устройство

```
office/
  main.py    запуск ботов, команды и маршрутизация сообщений
  team.py    логика офиса: диалоги, план, выполнение задач, итог
  brain.py   запросы к Claude API
  db.py      SQLite: история, лента общего чата, задачи (data/office.db)
  config.py  .env и agents.toml
```
